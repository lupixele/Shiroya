## 1. Explain different methods of data collection with suitable examples.

**Definition:** Data collection is the process of gathering facts and observations from relevant sources for analysis and decision-making.

### Methods of data collection
* **Surveys and questionnaires:** Ask people a fixed set of questions. Example: collecting student feedback about online classes.
* **Interviews:** Ask individuals questions directly to obtain detailed information. Example: interviewing customers about a product.
* **Observation:** Record events or behaviour as they occur. Example: counting the number of visitors entering a store.
* **Experiments:** Change one factor and observe its effect. Example: testing two website layouts to compare user responses.
* **Sensors and devices:** Automatically collect readings. Example: temperature sensors record room temperature.
* **Existing databases and records:** Use information already stored in systems. Example: hospital admission records.
* **Web scraping and APIs:** Collect permitted information from websites or services. Example: retrieving public weather data through an API.
* **Transactions and logs:** Use records generated by activities. Example: online orders and website click logs.

**Types of data sources:** Primary data is collected directly for the current purpose, such as a new survey. Secondary data was collected earlier by another person or organization, such as a published report.

### Factors for selecting a method
* Purpose of the study and type of information required.
* Time, cost and available resources.
* Accuracy, completeness and possible bias.
* Privacy, consent and legal requirements.
* Size and accessibility of the target population.

**Example:** To study student satisfaction, a college may conduct an online questionnaire, interview a small group and compare responses with attendance records.

**Conclusion:** The method should match the research question. Using reliable sources and collecting data ethically improves the quality of analysis.

## 2. What is data pre-processing? Explain the major steps involved in data pre-processing.

**Definition:** Data pre-processing is the process of converting raw data into a clean, consistent and suitable form before analysis or modelling.

### Major steps
1. **Data integration:** Combine information from different sources into one dataset. Example: joining student details with marks.
2. **Data cleaning:** Correct errors, remove duplicates and handle missing or inconsistent values.
3. **Data transformation:** Convert data into an appropriate format. This may include normalization, standardization and encoding categories.
4. **Data reduction:** Reduce data size while retaining useful information, for example by selecting relevant columns or summarizing records.
5. **Data discretization:** Convert continuous values into groups, such as age into age ranges, when suitable.
6. **Validation:** Check data types, ranges, uniqueness and consistency after preparation.

**Example:** A student dataset may contain blank marks, duplicate student IDs and marks stored as text. Pre-processing removes duplicates, investigates missing marks, converts marks to numbers and checks that values fall within the valid range.

### Importance
* Improves data quality and reliability.
* Makes analysis and model training more effective.
* Reduces errors caused by inconsistent formats.
* Helps combine data from multiple sources.
* Can reduce processing time and unnecessary complexity.

Pre-processing decisions should be documented. Missing values should not be filled blindly; the reason for missingness and the meaning of the variable must be considered.

![Concept diagram](figures/unit2_q2_preprocessing_stages.png)

**Conclusion:** Pre-processing is an essential step because the quality of the result depends strongly on the quality of the input data.

## 3. Explain data cleaning techniques with examples.

**Definition:** Data cleaning is the process of identifying and correcting inaccurate, incomplete, duplicate or inconsistent data.

### Common techniques
* **Handling missing values:** Remove a record only when appropriate, or fill a value using a justified method such as median or a clear 'Unknown' category.
* **Removing duplicates:** Identify repeated records using a unique ID or a combination of columns. Example: the same order entered twice.
* **Correcting data types:** Convert dates stored as text into date values and numeric text into numbers.
* **Standardizing formats:** Use one consistent date format and consistent spelling. Example: 'Vizag' and 'Visakhapatnam' may need a common category if they refer to the same place.
* **Range checks:** Find impossible values. Example: a percentage greater than 100 may indicate an error.
* **Outlier investigation:** Check unusually high or low values. Do not delete them automatically because they may be valid observations.
* **Text cleaning:** Remove unwanted spaces, fix case differences and standardize labels.

### Python examples
```python
df = df.drop_duplicates()
df["Marks"] = pd.to_numeric(df["Marks"], errors="coerce")
df["Name"] = df["Name"].str.strip()
```
These examples remove duplicate rows, convert marks to numeric values and remove extra spaces from names.

### Advantages
* Improves accuracy of summaries and charts.
* Prevents avoidable errors in later analysis.
* Makes datasets consistent and easier to combine.
* Improves trust in reports and models.

**Important caution:** Keep an original copy of the data. Record every cleaning decision and check whether a correction changes the meaning of the data.

![Concept diagram](figures/unit2_q3_data_cleaning_flow.png)

**Conclusion:** Cleaning makes data more dependable by correcting quality problems while preserving valid information.

## 4. Explain different techniques for handling missing values with an example.

**Definition:** Missing values are entries for which no value is recorded. Handling missing values means choosing a suitable way to manage these blanks before analysis.

### Techniques
1. **Delete rows:** Remove records with missing values when only a small number are affected and deletion will not create bias.
2. **Delete a column:** Consider removing a column if most of its values are missing and it is not important.
3. **Mean imputation:** Replace missing numerical values with the mean. It is sensitive to extreme values.
4. **Median imputation:** Replace missing numerical values with the median. It is often more robust when data is skewed.
5. **Mode imputation:** Replace missing categorical values with the most frequent category.
6. **Constant or category imputation:** Use a meaningful value such as 0 only when appropriate, or label a category as 'Unknown'.
7. **Forward/backward fill:** Use a nearby previous or next observation, mainly for ordered time-series data when justified.

**Example:** Marks = 60, 70, blank, 80, 90. The mean of the available values is 75, and the median is also 75. A missing mark could be filled with 75 for a simple demonstration, but a real study should consider why the mark is missing and whether this method is suitable.

### Simple Python examples
```python
df['Age'] = df['Age'].fillna(df['Age'].median())  # fills missing age values using the median
df['City'] = df['City'].fillna('Unknown')         # labels missing city values
df = df.dropna()                                  # removes rows containing missing values
```

**How to choose:** Consider the percentage of missing values, the data type, the reason values are missing and the effect on analysis. Fit imputation values using training data only when building predictive models, to avoid data leakage.

![Concept diagram](figures/unit2_q4_missing_values_flow.png)

**Conclusion:** There is no single best method. Select the method carefully and explain the reason for using it.

## 5. Explain normalization and standardization. Compare them with suitable examples and formulas.

**Definition:** Normalization and standardization are feature-scaling techniques. They place numerical variables on comparable scales so that variables with large units do not dominate certain algorithms.

### 1. Normalization (Min-Max scaling)
* Converts values to a selected range, commonly 0 to 1.
* **Formula:**
  $$x' = \frac{x - X_{\min}}{X_{\max} - X_{\min}}$$
* **Example:** For values 10, 20 and 30, the normalized value of 20 is $(20-10)/(30-10) = 0.5$.
* Useful when a bounded range is desired, such as for some distance-based methods and neural-network inputs.

### 2. Standardization (Z-score scaling)
Changes values so that the transformed feature has mean 0 and standard deviation 1 (on the data used to calculate them).
* **Formula:**
  $$z = \frac{x - \mu}{\sigma}$$
  where $\mu$ is the mean and $\sigma$ is the standard deviation.
* **Example:** If mean = 50, standard deviation = 10 and $x = 70$, then $z = (70-50)/10 = 2$.

### Comparison
* Normalization usually produces a fixed range such as 0 to 1; standardization does not have a fixed minimum or maximum.
* Normalization depends on the minimum and maximum and can be strongly affected by extreme values.
* Standardization uses mean and standard deviation and is often useful for algorithms sensitive to feature scale.
* Both should be fitted on training data and then applied to validation/test data using the same parameters.

**Applications:** Scaling can help K-nearest neighbours, clustering, support vector machines and gradient-based learning. Tree-based models are generally less sensitive to feature scaling.

**Conclusion:** Use normalization when a fixed range is useful and standardization when centering and scaling around the mean is appropriate.

## 6. What is feature engineering? Explain different feature engineering techniques with examples.

**Definition:** Feature engineering is the process of creating, transforming or selecting input variables (features) so that they represent a problem more usefully for analysis or machine learning.

### Techniques
* **Feature creation:** Create a new variable from existing ones. Example: $\text{Total} = \text{Quantity} \times \text{Unit Price}$.
* **Feature extraction:** Obtain useful information from raw data. Example: extract year, month and weekday from a date.
* **Encoding categorical variables:** Convert categories into numbers. One-hot encoding creates indicator columns; label encoding assigns codes when appropriate.
* **Scaling:** Normalize or standardize numerical features so they use comparable scales.
* **Binning:** Convert continuous values into groups. Example: age into age bands.
* **Text features:** Convert text into useful features such as word counts or TF-IDF values.
* **Feature selection:** Keep relevant variables and remove irrelevant or redundant ones using domain knowledge or statistical/model-based methods.

**Example:** For predicting delivery time, raw order date can be transformed into weekday and hour. Distance and traffic level may be useful features. A feature such as 'delivery zone' may be encoded for a model.

### Benefits
* Can improve model performance and interpretability.
* Uses domain knowledge to represent the problem.
* May reduce irrelevant information.
* Can reveal useful patterns that are not obvious in raw columns.

**Precautions:** Avoid using information that would not be available at prediction time. Prevent data leakage, document transformations and check whether created features are meaningful.

![Concept diagram](figures/unit2_q6_feature_engineering_flow.png)

**Conclusion:** Good features help a model learn useful patterns; feature engineering should be guided by the problem and the available data.

## 7. Explain feature scaling with suitable example.

**Definition:** Feature scaling is the process of adjusting the scale or range of numerical input variables so that they can be compared fairly during analysis or model training.

### Why scaling is needed
* Features may use different units. Example: age may range from 18 to 60, while income may range from thousands to lakhs.
* Distance-based methods can give greater influence to a feature with larger numerical values.
* Some optimization methods work more efficiently when features have comparable scales.

### Common methods
* **Min-Max normalization:**
  $$x' = \frac{x - \min}{\max - \min}$$
* **Z-score standardization:**
  $$z = \frac{x - \text{mean}}{\text{standard deviation}}$$

**Example:** Suppose a person's height is 170 cm and the dataset range is 150–190 cm. Normalized height = $(170-150)/(190-150) = 0.5$.

### Applications and advantages
* K-nearest neighbours uses distances, so scaling can matter.
* K-means clustering uses distances, so scaling can matter.
* Support vector machines and many gradient-based models can benefit from scaling.
* It prevents large-scale variables from dominating solely because of their units.

**Important difference:** Feature scaling is the general process. Normalization and standardization are two common methods used to perform it. Scaling is not always required for every algorithm, especially many decision-tree-based methods.

![Concept diagram](figures/unit2_q7_feature_scaling_flow.png)

**Conclusion:** Feature scaling makes numerical features comparable and can improve the behaviour of scale-sensitive algorithms.

## 8. Explain data integration and data aggregation with suitable example.

**Definition:** Data integration combines data from different sources into a unified dataset. Data aggregation summarizes detailed records into grouped or higher-level information.

### Data integration
* Combines information from multiple files, databases or systems.
* Uses common fields such as student ID, customer ID or product code to match records.
* Requires handling different column names, formats, duplicate records and conflicting values.
* **Example:** Combine a student-details table with a marks table using `Student_ID`.

### Data aggregation
Groups records and calculates summary values such as sum, count, average, minimum or maximum.  
**Example:** Daily sales transactions can be grouped by month to calculate monthly total sales and average order value.

### Difference
* Integration focuses on bringing data sources together.
* Aggregation focuses on summarizing data into a smaller set of meaningful results.
* Integration may happen before aggregation in a data workflow.

### Simple SQL examples
```sql
SELECT s.Student_ID, s.Name, m.Marks
FROM Student s
JOIN Marks m ON s.Student_ID = m.Student_ID;

SELECT Month, SUM(Sales) AS Total_Sales
FROM Orders
GROUP BY Month;
```

**Advantages:** Integration gives a broader view across sources. Aggregation makes large datasets easier to understand, compare and report. Both require checking data quality and consistent definitions.

![Concept diagram](figures/unit2_q8_integration_aggregation_flow.png)

**Conclusion:** Integration combines records; aggregation summarizes them. They are often used together in data analysis.
