## Key Notes Verification Summary

For full line-by-line analyses, see [`Handwritten Notes Verification.md`](Handwritten%20Notes%20Verification.md):
- **Slide 141 Arithmetic Error (Unit 3 PPT):** In sampling without replacement, $\sum(\bar{x}_i - \mu)^2 = 120$ (not $133$), giving $\sigma_{\bar{x}} = \sqrt{12} \approx 3.4641$ (not $3.65$).
- **Notes Page 11 Fatal Harmonic Mean Error:** Author calculated H.M. as $0.135$ by dividing by $N$ without reciprocating. The true value is $\frac{N}{\sum(1/x)} = 6.3508$.
- **Hypothesis Formulation Mistake (Q7):** Notes wrote alternative hypothesis $H_1$ identical to null hypothesis $H_0$. Corrected to state that sampling techniques are significantly different.
- **Arithmetic Mistake (Q8):** Notes calculated $\frac{144}{50} = 2.8$ instead of $2.88$, skewing subsequent test statistic values.
- **Regression Product Formula Error (Q15):** Notes wrote $r^2 = b_{yx} + b_{xy}$ with a plus sign. Corrected to the geometric mean formula $r^2 = b_{yx} \cdot b_{xy}$.
- **Paired Data Methodology:** Corrected `testing of Hypothesis.pdf` where independent two-sample $t$-test was mistakenly applied to paired before/after measurements on the same individuals.
