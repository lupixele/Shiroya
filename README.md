# Shiroya

Academic exam notes and study resources collected for the Shiroya Discord community.

Shiroya is a student-focused knowledge hub where members share clean, exam-oriented notes, worked answers, and quick revision material for major academic subjects. This repository aims to keep those resources organized, searchable, and easy to access from anywhere.

## About this repository

This repo contains notes and study materials for multiple courses, mainly focused on exam preparation and semester revision. It is intended to help students revise concepts quickly, review solved examples, and prepare for internal and university examinations.

## Repository structure

```text
Shiroya/
├── ADSA/
├── DBMS/
├── EMP/
├── P&S/
├── README.md
```

## Subjects included

- ADSA — Design and Analysis of Algorithms
- DBMS — Database Management Systems
- EMP — Quantitative aptitude and reasoning study materials
- P&S — Probability and Statistics notes and reference materials

## Purpose

- Centralize study notes from the Shiroya Discord server
- Provide exam-ready resources for quick revision
- Organize notes by subject and topic
- Make learning materials easier to share and access

This repository is designed for academic study use and is best suited for:
