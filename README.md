# Shiroya

Academic exam notes and study resources collected for the Shiroya Discord community.

Shiroya is a student-focused knowledge hub where members share clean, exam-oriented notes, worked answers, and quick revision material for major academic subjects. This repository aims to keep those resources organized, easy to search, and useful for exam preparation.

## About this repository

This repo contains notes and study materials for multiple courses, mainly focused on exam preparation and semester revision. It is intended to help students revise concepts quickly, review solved examples, and access academic resources in one place.
